# JavaScript Practice / Cheat Code 🧠

A public collection of small, hands-written JavaScript exercises; built while going back to fundamentals after realizing I'd started leaning on AI a bit too much for day-to-day coding.

The goal of this repo is twofold:
- **For me:** rebuild real, independent problem-solving skills; writing code from a blank file, no autocomplete crutches.
- **For anyone else:** a free, public reference for core JS concepts, explained through small runnable examples. If you're learning JS or just need a quick reminder of how something works, feel free to browse, clone, or fork this.

I'm not a guru just yet, this is a learning-in-public project, mistakes and all.

## What's in here

| File | Concepts covered |
|---|---|
| `hello.js` | Basics: variables, functions, conditionals, loops |
| `spread.js` | Spread/rest operators, array & object manipulation |
| `callbacks.js` | Functions as values, passing callbacks, `setTimeout`, non-blocking behavior |
| `closures.js` | Closures, private state, the classic `var` vs `let` loop trap |

More files will be added as I work through TypeScript, React, and backend fundamentals.

## How to run any file

```bash
node filename.js
```

(Requires [Node.js](https://nodejs.org/) installed.)

## Why this exists

I noticed I could *read* and *understand* code well, but took too much time writing things independently, a common trap when AI tools handle too much of the thinking (which is not wrong by any means). So I'm working through each JS concept by hand: predicting output before running code, debugging my own mistakes, and only reaching for help after a genuine attempt.

This repo is the paper trail of that process.
